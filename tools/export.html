For use with Live Server

Update the catalog.
Export the pages.

Generate static HTML in your browser. No npm, installation, or command line is required.

  1. Edit songs.js in your site folder. Use the current constructor format and a permanent slug.
  2. Open this page through Live Server and select Export updated pages.
  3. Extract the downloaded ZIP into the site folder, replacing matching files. The ZIP contains generated HTML and catalog metadata; keep your existing images, audio, CSS, and JavaScript.
  4. Preview your changes, then publish the updated folder.

To adjust the song layouts, edit the files in templates/ before exporting. The home page retains your edits outside its song-list markers.

Your files stay in your browser. This tool does not upload or publish them.

About existing songs and drafts

The compatibility data in data/legacy-songs.json preserves older published pages until you finish migrating them. Old-format catalog entries remain drafts. Migrated records take precedence. To withhold a migrated song, set its published property to false.
